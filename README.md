## Как играть
Открой сайт GitHub Pages (после активации в Settings → Pages → GitHub Actions), выбери игру и нажми «Играть». Для офлайн-запуска скачай нужный HTML-файл, затем открой его в браузере. Некоторые компьютеры или браузеры могут ограничивать локальный запуск, поэтому работа без интернета не гарантируется.

**Источник пяти HTML-файлов:** https://github.com/LeeBingsu/UNDERTALE (сверены по Git blob SHA с загруженным архивом пользователя 16.11.2026). Авторы указаны выше. Неофициальные фанатские проекты, не связанные с создателем оригинальной UNDERTALE. Оригинальную игру проект не заменяет.

## Автоматический импорт
Файл `.github/workflows/deploy.yml` загружает пять HTML-файлов из указанного исходного репозитория, фиксирует их в данном репозитории и пытается опубликовать сайт через Pages. Если Pages ещё не включён, открой Settings → Pages → Source → **GitHub Actions**, затем перезапусти задачу на вкладке Actions.
